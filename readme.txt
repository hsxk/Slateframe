A fast, accessible, multilingual-ready WordPress theme for publishing, photography, blogs, portfolios, and personal websites.

== Description ==

Slateframe is a content-first hybrid WordPress theme. It uses native WordPress templates, theme.json, reusable block styles, system fonts, and lightweight JavaScript.

Slateframe is language-agnostic by default. It does not require a multilingual plugin and does not assume a fixed locale list or locale URL structure.

The theme includes reusable block styles and starter patterns for photo essays, project case studies, and structured learning paths. Wide and full-width blocks can expand beyond the normal reading measure while regular prose remains comfortably constrained.

== Installation ==

1. Upload the Slateframe theme directory to /wp-content/themes/.
2. Activate Slateframe in Appearance > Themes.
3. Assign Primary and Footer menus as desired.
4. Optionally set a custom logo and use the block editor to build content.

== Frequently Asked Questions ==

= Does Slateframe require a page builder? =

No. Slateframe is designed around WordPress core templates, blocks, patterns, and theme.json.

= Does Slateframe require a multilingual plugin? =

No. The theme works with WordPress locales directly. Multilingual plugins can integrate through public theme hooks without becoming core dependencies.
