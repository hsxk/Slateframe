# Security Policy

## Supported versions

Slateframe is in pre-release development. Security fixes are applied to the latest validated `main` line and the active development branch until the first stable release defines a longer support window.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Active pre-release development | Yes |
| Older development SHAs | No guarantee |

## Reporting a vulnerability

Please do not disclose an exploitable vulnerability in a public issue before maintainers have had a reasonable opportunity to investigate it.

Use GitHub's **Security** tab and **Report a vulnerability** when private vulnerability reporting is available. Include:

- affected version or commit;
- reproduction steps;
- expected security impact;
- whether authentication or special configuration is required;
- any proposed mitigation or patch.

Non-sensitive bugs, accessibility issues, and hardening suggestions can use normal GitHub issues.

## Scope

Slateframe is a presentation theme. Reports about WordPress core, unrelated plugins, hosting infrastructure, third-party CDNs, or site-specific application logic should be reported to the responsible project instead.
