# Bounded Core Project and Learning feature spacing

The native `slateframe/project-case-study` and `slateframe/learning-path` patterns use WordPress Core Group, Columns, Headings and Paragraphs. Their shared feature-group presentation previously reserved `1.5rem` of block padding at mobile widths, which became 96px on each side at a 64px root font. On larger screens, `clamp(1.75rem,4vw,3.25rem)` could reserve 112px or more per side. This consumed vertical reading space without adding meaning, especially in long CJK/RTL learning paths.

The mobile block padding is now `min(1.5rem,40px)` and the desktop rule is `min(clamp(1.75rem,4vw,3.25rem),64px)`. Normal 16px presentation is unchanged: 24px on mobile and the original fluid 28–52px desktop rhythm. At 390px/400%, the mobile value becomes 40px instead of 96px; at 1440px/400%, it becomes 64px instead of 112px. Text size, native blocks, author-controlled layout, RTL logical geometry, 44–56px controls, Gutenberg shared CSS and all existing 7,000-byte/aggregate budgets are preserved. No new runtime CSS request, JavaScript, dependency or content ownership is introduced.

An independent Chromium preflight using the actual theme CSS compared 84 old/new width, direction and font combinations (7 × 2 × 3 × 2), with no horizontal overflow or incorrect computed padding. A second 42-state replay rendered the actual PHP patterns with WordPress-neutral translations and Core Columns, also with zero document overflow. These are diagnostic, **not** GitHub Actions acceptance. The real WordPress browser test renders both registered patterns in one disposable page, checks 42 responsive/direction/scale states, runs Axe and forced-colors checks, verifies native Gutenberg block validity and editor spacing, and records 390px RTL/400% plus 1440px LTR screenshots. Three 390×900 evidence PNGs are mandatory and rejected if missing, truncated, corrupt, wrong-size or symlinked. Exact HEAD Actions success, downloaded actual screenshot review and release ZIP audit remain prerequisites for merging.
