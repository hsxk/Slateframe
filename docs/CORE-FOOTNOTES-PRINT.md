# Core Footnotes in print

Slateframe keeps native Core Footnotes as inline references and numbered list items when printing. Screen return links use the Appearance control target (44px minimum; 56px in spacious), but a printed return arrow does not need a touch-sized box. The bounded screen control rule is explicitly scoped to `@media screen`, so the existing print stylesheet retains native inline link geometry while preserving numbering, content, and black-on-white presentation. The print-only stylesheet suppresses keyboard focus rings, and the screen-only target highlight never prints even after an anchor jump. Screen focus and target feedback remain unchanged. No script, block replacement, or export plugin is introduced.

`tests/browser/core-footnotes-print.spec.js` verifies the actual WordPress print stylesheet is enqueued, compares the screen target with the print geometry, checks RTL containment and black-on-white ink, verifies that both the footnote and its source reference are outlined on screen but not on paper, and captures 390px/1440px print-media evidence. The existing 3KB print CSS budget remains enforced without increasing its threshold. This patch is not accepted until its exact PR HEAD passes Theme quality Actions and its screenshots have been visually reviewed.
