# Native Core Previous/Next Post navigation

Slateframe uses WordPress Core `core/post-navigation-link` for adjacent-post
resolution, link destinations, labels and Gutenberg attributes. The theme does
not query adjacent posts, invent routes or replace native navigation with JS.

The existing conditional `assets/css/core-post-navigation.css` gives authored
Previous/Next links a bounded 44px minimum hit target and safe logical wrapping.
It is registered via `wp_enqueue_block_style()` and also included in
`add_editor_style()`. Pages without the block do not load its frontend asset.

## Automated acceptance

A disposable three-post WordPress fixture uses distinct 1999 publication dates
to establish a previous/current/next sequence. Browser tests verify native
permalinks and adjacent titles before applying DOM-only CJK/RTL/long-label
stress. Chromium covers 320/375/390/412/768/1440/1920px, LTR/RTL, 200%/400%
text zoom, horizontal overflow, 44px targets, keyboard focus, Axe, forced
colors, screenshot evidence and no-asset behavior on an unrelated 404 page.

The authenticated Gutenberg test checks that native direction, title and label
options roundtrip through Core serialization without modifying an existing
editor fixture. All disposable posts are deleted in `finally`.

## Release review

Inspect the screenshots generated by the exact PR HEAD before merging.
Manual Safari/VoiceOver and Firefox checks remain necessary for the
localized Previous/Next announcements, keyboard focus order and zoom.
The test is a presentation contract, not a replacement for Core navigation.
